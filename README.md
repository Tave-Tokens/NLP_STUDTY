#  🔤토큰즈 - TAVE 17기 딥러닝 스터디

## 📌 스터디 개요

자연어 처리(NLP)와 딥러닝 기반 언어 모델의 이론 및 실습 스터디입니다.  
전통적 텍스트 표현 방법부터 Transformer, BERT, ChatGPT, 멀티모달 AI까지 현대 NLP의 전체 흐름을 체계적으로 학습합니다.

### 🎯 학습 목표

- NLP 핵심 개념(BOW, Word Embedding, RNN, Transformer) 이해 및 설명
- Seq2Seq · Attention · BERT 구조를 수식과 코드 수준에서 이해
- Hugging Face 등 실무 라이브러리를 활용한 태스크 직접 수행
- 최신 생성형 AI(ChatGPT, DALL-E, CLIP)의 작동 원리 파악
- 매주 발표·토론·코드 리뷰를 통한 협업 및 커뮤니케이션 역량 향상

## 📅 주차별 커리큘럼

| 주차 | 주제 | 핵심 내용 | 과제 |
|------|------|-----------|------|
| 1주차 | Deep Learning Sequence Model | RNN, LSTM, Tokenization, 감성 분석, NER | 네이버 영화 리뷰 감성 분석 with LSTM (정확도 85% 이상) |
| 2주차 | Language Model | Seq2Seq, Teacher Forcing, Encoder-Decoder, 챗봇 | Teacher Forcing 유무에 따른 Seq2Seq 번역 모델 비교 |
| 3주차 | Transformers | Attention, Self-Attention, Multi-Head Attention, Positional Encoding | Scaled Dot-Product Attention 구현 및 Shape 분석 |
| 4주차 | 자연어 전이 학습 모델 | ELMo / BERT / GPT, Fine-Tuning, Hugging Face | BERT Fine-Tuning 기반 감성 분석 및 LSTM 성능 비교 |
| 5주차 | ChatGPT와 멀티모달 AI | RLHF, ViT, CLIP, DALL-E, 멀티모달 AI | CLIP 기반 이미지-텍스트 유사도 분석 및 Zero-shot 분류 |
